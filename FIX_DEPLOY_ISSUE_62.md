### Diagnóstico Técnico

El comando `vista deploy` y sus adaptadores de despliegue presentan fallos de inconsistencia al generar artefactos e instrucciones para diferentes plataformas:

1. **Cloudflare Pages (`_redirects`)**: La regla de captura general (catch-all SPA) intercepta las peticiones de React Server Components (`/rsc/*`), reescribiéndolas a HTML en lugar de mantener el payload Flight `.rsc`. Esto fuerza un re-renderizado completo o falla la hidratación en navegación cliente.
2. **Render / Docker Adapter**: Los archivos `render.yaml` y `Dockerfile` generados no apuntan correctamente al punto de entrada standalone `.vista/standalone/server.js`, utilizando comandos obsoletos (`npm start` o rutas incorrectas).
3. **Vercel / Netlify Function Packaging**: La ejecución del compilador del adaptador omite copiar la carpeta standalone `.vista/standalone/` y sus dependencias al paquete de la función servidora, provocando errores `MODULE_NOT_FOUND` al ejecutar en entorno de producción o durante `--dry-run`.
4. **Cloudflare Target Disambiguation**: La resolución de `--target cloudflare` confunde despliegues de Pages (estático/functions) con Workers/Containers (`wrangler.toml`), emitiendo archivos en conflicto.

#### 1. Corrección del generador de Cloudflare Pages (`packages/vista/src/cli/deploy/adapters/cloudflare.ts`)

```typescript
import { join } from 'node:path';
import { writeFileSync, existsSync, mkdirSync } from 'node:fs';

export interface DeployOptions {
  outDir: string;
  dryRun?: boolean;
  standalone?: boolean;
  mode?: 'static' | 'functions' | 'container';
}

export async function generateCloudflareAdapter(opts: DeployOptions): Promise<void> {
  const { outDir, dryRun, mode = 'static' } = opts;

  if (mode === 'static') {
    // Generar _redirects asegurando precedencia estricta para rutas Flight /rsc/
    const redirectsContent = [
      '# Vista Framework - Cloudflare Pages Redirects',
      '# Preserve Flight payload routes without HTML rewrite',
      '/rsc/*  /rsc/:splat  200',
      '/_vista/*  /_vista/:splat  200',
      '/*  /index.html  200'
    ].join('\n');

    if (!dryRun) {
      if (!existsSync(outDir)) mkdirSync(outDir, { recursive: true });
      writeFileSync(join(outDir, '_redirects'), redirectsContent, 'utf-8');
    }
  } else if (mode === 'container') {
    const wranglerConfig = [
      'name = "vista-app"',
      'main = ".vista/standalone/server.js"',
      'compatibility_date = "2024-01-01"',
      '[site]',
      'bucket = "./.vista/static"'
    ].join('\n');

    if (!dryRun) {
      writeFileSync('wrangler.toml', wranglerConfig, 'utf-8');
    }
  }
}
```

#### 3. Corrección del empaquetado Vercel / Netlify (`packages/vista/src/cli/deploy/adapters/standalone-packer.ts`)

```typescript
import { cpSync, existsSync, mkdirSync } from 'node:fs';
import { join } from 'node:path';

export function packStandaloneTarget(targetDir: string): void {
  const standaloneSource = join(process.cwd(), '.vista', 'standalone');
  
  if (!existsSync(standaloneSource)) {
    throw new Error(
      'Standalone build missing. Run `vista build` before running `vista deploy`.'
    );
  }

  mkdirSync(targetDir, { recursive: true });

  // Copia recursiva garantizada del servidor standalone y sus node_modules aislados
  cpSync(standaloneSource, targetDir, { recursive: true });
}
```
