Vista is currently in its alpha stage. It is a framework born from a desire for simplicity without sacrificing power.

If you have used Next.js, Vista will feel familiar by design. It follows practical conventions while keeping the runtime lightweight.

## Core Promise

- Write less code for common product workflows.
- Keep server-first performance defaults.
- Retain flexibility when apps grow beyond starter templates.

## Current Stage

Vista is moving fast. APIs that reduce boilerplate are prioritized first, then ecosystem depth follows.
